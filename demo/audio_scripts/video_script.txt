# 動画用台本: 独行の === でブロック区切り。ブロック n がスライド n 枚目に対応。
# 先頭が # の行は合成されません。
これは、Marp のスライドと日本語のナレーション、テキスト読み上げ音声、
それから Remotion を組み合わせて、音声付きのスライド動画を作る方法のデモです。
4 枚のこのデッキが、そのままデモの素材になっています。
===
第一步は、台本とスライドを一枚ずつ、一対一に対応させることです。
スライド一枚に対して、ナレーションは一区切りだけ。
音声用のスクリプトは、二重角括弧で PAUSE と秒数を書いた行で区切り、
動画用のスクリプトは、イコール三つの行でブロックを区切ります。
===
第二步は、音声の合成とタイミングの計測です。
成果物は三つ。スライドの PNG は Marp のコマンドラインで作ります。
セクション音声は、TTS の API で MP3 モノラル六十四キロbps に変換します。
そしてタイミングファイルは、音声の実測長に余白の一秒二を加えて、フレーム数に直します。
===
第三步は、Remotion での動画化です。
タイミングファイルに従って、音声の一ブロックが一スライドで再生されます。
レンダリングは remotion render のコマンド一発です。
音声だけ、あるいは動画だけ、どちらだけでも出力できます。
